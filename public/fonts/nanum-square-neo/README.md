# NanumSquareNeo

Original, unmodified WOFF2 files from Naver's official font package.
Self-hosted: no runtime CDN dependency. All original glyphs are retained.

- Font and download: https://campaign.naver.com/nanumsquare_neo/
- Archive: https://campaign.naver.com/nanumsquare_neo/download/NaverNanumSquareNeo.zip
- License: https://help.naver.com/service/30016/contents/18088

- SIL Open Font License 1.1: see OFL.txt.

CSS family: `NanumSquareNeo`. Weights: Light 300, Regular 400, Bold 700,
ExtraBold 800, Heavy 900. Only the weights used on a page are downloaded.
