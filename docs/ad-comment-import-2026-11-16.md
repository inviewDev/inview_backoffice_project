- 기존 댓글 110건의 ID·내용·작성자·작성일·수정일·공개 구분이 변경되지 않았음을 이관 트랜잭션 안과 운영 검증 후에 확인했다.

- 원본 한국시간을 명시적으로 UTC로 변환해 초 단위까지 보존했다.
- 원본 계정에서 열람 가능한 일반 댓글이 대상이다. 기존 계정에서는 관리자 전용 댓글 영역이 노출되지 않아 그 영역의 완전성을 보장하지 않는다.

## 구현과 재실행

- `AdComment`에 작성자 스냅샷과 고유 원본 식별값을 추가하고 작성자 계정 연결을 선택값으로 바꿨다.
- 기존 일반 댓글 작성 API, 수정·삭제 권한, 관리자 댓글 접근 권한은 변경하지 않았다.
- 원본 그리드에 댓글 ID가 없으므로 광고 번호·공개 구분·작성자·작성일·내용의 SHA-256과 동일 원문 출현 순번으로 이관 식별값을 만든다. 원본에 동일 댓글이 실제 여러 개 있으면 각각 보존한다.
- `scripts/import-legacy-ad-comments.cjs`는 기본 dry-run이며 `--apply`일 때만 추가한다. UPDATE/DELETE는 실행하지 않는다.
- 동일 원본으로 재실행 시 `newComments: 0`, `alreadyImported: 2655`를 확인했다.
- API 응답은 원본 작성자명 스냅샷을 우선 표시하고 신규 일반 댓글은 기존 계정명 표시를 유지한다.
- 기존 데이터의 작성일·작성자 변경 없이 스키마만 확장했다.
